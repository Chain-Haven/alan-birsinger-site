Accessibility

Built to be readable for everyone.

This site is designed to meet WCAG 2.2 AA standards. If anything is hard to read, hard to navigate, or otherwise inaccessible, please tell us — we'll fix it.

Our approach

  • High color contrast across text and interactive elements.
  • Generous default body text size (17–18px) and line spacing.
  • Keyboard-accessible navigation and form controls.
  • Meaningful alt text on imagery; captions where used.
  • Reduced-motion preferences respected.
  • Logical heading hierarchy and landmark regions.
